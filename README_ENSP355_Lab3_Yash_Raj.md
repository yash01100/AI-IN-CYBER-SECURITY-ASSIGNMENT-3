## Assignment Overview

This lab uses a prepared cyber-activity dataset to classify records as:

-   `0` -- Normal
-   `1` -- Attack

The practical covers CNN, RNN/LSTM and GAN concepts, dataset
preparation, feature normalization, a 4--8--4--1 dense neural network,
learning-curve interpretation, new-record predictions, and comparison
with a Decision Tree.
